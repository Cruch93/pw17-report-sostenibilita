# Project Work — CdS Informatica per le Aziende Digitali (L-31)

**Tema n. 3: Tecnologia web per la sostenibilità d’impresa**

**Traccia del PW 17: Sviluppo di una pagina web per il download dei report di sostenibilità di un’impresa del settore primario**

L’azienda scelta è **Fasoli Gino**, azienda vitivinicola del territorio veronese molto attenta alla sostenibilità del territorio.

La pagina ha lo scopo di rappresentare le principali attività dell’azienda in termini di sostenibilità e offre la possibilità di scaricare facilmente i relativi report.


## Tecnologie utilizzate

Per la realizzazione della pagina sono stati utilizzati **HTML5** e **CSS3**.

Per la gestione del layout sono stati utilizzati principalmente **Flexbox** e **CSS Grid**.

Il codice è stato progettato in modo **responsive**, così da adattare correttamente i contenuti anche a schermi di dimensioni ridotte, come quelli di smartphone e tablet.


## Struttura del progetto

Il progetto è organizzato in una struttura semplice, in modo da mantenere separati il contenuto della pagina, lo stile grafico e le risorse utilizzate.

```text
PW17-Fasoli-Gino/
│
├── index.html
├── css/
│   └── style.css
├── img/
└── report/
```

Il file `index.html` contiene la struttura e i contenuti principali della pagina web.

Il file `css/style.css` contiene le regole utilizzate per definire l’aspetto grafico, il layout e il comportamento responsive della pagina.

La cartella `img` contiene le immagini e i loghi utilizzati nel progetto.

La cartella `report` contiene i bilanci di sostenibilità messi a disposizione per la consultazione e il download.
